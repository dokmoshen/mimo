# Mimo — промо для TikTok

Вертикальный ролик 9:16, собранный из реального интерфейса Mimo 1.13.0.

## Файлы

- `mimo-tiktok-1080x1920.mp4` — версия с оригинальным битом.
- `mimo-tiktok-silent.mp4` — без звука, чтобы наложить трендовую музыку в TikTok.
- `mimo-tiktok-cover.png` — обложка 1080×1920.

## Параметры

- 1080×1920, 30 fps, H.264 + AAC.
- Длительность: 22,5 секунды.
- Русские подписи в кадре, без необходимости включать звук.

## Музыка

Бит сгенерирован специально для ролика, сторонних треков нет. Для TikTok можно взять `mimo-tiktok-silent.mp4` и наложить звук из библиотеки TikTok — подписи уже в кадре.

- Шрифты: Unbounded, Manrope, Handjet (SIL OFL).
- Иконки и интерфейс: Mimo 1.13.0.
- Запись экрана: эмулятор Android 15, 1080×2400.
