# Mimo — промо для TikTok (2.5D)

Вертикальный ролик 9:16, собранный из скриншотов Mimo 1.13.0 без записи экрана. Интерфейс живёт на наклонных 3D-плоскостях: лёгкий параллакс, плавающие детали, мягкие тени и глубина.

## Файлы

- `mimo-tiktok-1080x1920.mp4` — версия с оригинальным битом (~19 МБ).
- `mimo-tiktok-silent.mp4` — без звука, чтобы наложить трендовую музыку в TikTok (~19 МБ).
- `mimo-tiktok-cover.png` — обложка 1080×1920 из первого кадра.

## Параметры

- 1080×1920, 9:16, 30 fps, H.264 + AAC, 48 кГц.
- Длительность: 22,5 секунды.
- Русские подписи в кадре, звук можно не включать.

## Таймлайн

| Время | Сцена |
|---|---|
| 0:00–0:02 | Хук: «Твои заметки не для рекламы» + парящий экран приложения |
| 0:02–0:05 | Nothing-режим: технические карточки, монохром |
| 0:05–0:09 | Док → меню → быстрый захват |
| 0:09–0:11 | Смена темы точечной волной |
| 0:11–0:14 | Expressive: цвет, бумага, корешки меток |
| 0:14–0:17 | Редакционная читалка |
| 0:17–0:19,5 | Чек-лист: штамп, линия, прогресс |
| 0:19,5–0:22,5 | Финальная карточка с сайтом и GitHub |

## 2.5D

- Основной экран — наклонная плоскость с перспективой и мягкой тенью.
- Детали интерфейса вынесены вперёд отдельными карточками с другим углом и параллаксом.
- Подписи — отдельный слой, который «плавает» над сценой.
- Фон — размытый цвет сцены, точечная сетка и медленные частицы.

## Музыка

Бит сгенерирован специально для ролика, сторонних треков нет. Для TikTok можно взять `mimo-tiktok-silent.mp4` и наложить звук из библиотеки TikTok — подписи уже в кадре.

## Материалы

- Шрифты: Unbounded, Manrope, Handjet (SIL OFL).
- Иконки и интерфейс: Mimo 1.13.0.
- Исходники: скриншоты 1080×2400, снятые на эмуляторе Android 15.
