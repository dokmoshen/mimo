# Mimo — промо для TikTok (Remotion)

Вертикальный ролик 9:16, полностью собранный в Remotion из скриншотов Mimo 1.13.0. Запись экрана не используется: интерфейс живёт на наклонных 3D-плоскостях с параллаксом, мягкими тенями и плавающими деталями.

## Файлы

- `mimo-tiktok-1080x1920.mp4` — версия с оригинальным битом (~11 МБ).
- `mimo-tiktok-silent.mp4` — без звука, для трендового аудио в TikTok (~10 МБ).
- `mimo-tiktok-cover.png` — обложка 1080×1920 из кадра с хуком.
- `remotion/` — исходник композиции.

## Параметры

- 1080×1920, 9:16, 30 fps, H.264 + AAC, 48 кГц.
- Длительность: 22,5 секунды (675 кадров).
- Русские подписи в кадре.

## Remotion

Проект создан на Remotion `4.0.547`. Официальные Remotion Skills установлены глобально в OpenCode и локально в `remotion/.agents/skills`.

```bash
cd remotion
npm run dev          # Studio
npx remotion render MimoPromo out/mimo.mp4 --codec=h264 --audio-codec=aac
```

Если автоматическая загрузка Chrome Headless Shell блокируется сетью, скачайте его с `storage.googleapis.com/chrome-for-testing-public` и передайте путь:

```bash
npx remotion render MimoPromo out/mimo.mp4 \
  --browser-executable=/path/to/chrome-headless-shell
```

## Таймлайн

| Время | Сцена |
|---|---|
| 0:00–0:02 | Хук: «Твои заметки не для рекламы» + парящий экран |
| 0:02–0:05 | Nothing-режим: технические карточки, монохром |
| 0:05–0:09 | Док → меню → быстрый захват |
| 0:09–0:11 | Смена темы точечной волной |
| 0:11–0:14 | Expressive: цвет, бумага, корешки меток |
| 0:14–0:17 | Редакционная читалка |
| 0:17–0:19,5 | Чек-лист: штамп, линия, прогресс |
| 0:19,5–0:22,5 | Финальная карточка с сайтом и GitHub |

## Музыка

Бит сгенерирован специально для ролика, сторонних треков нет. Для TikTok можно взять `mimo-tiktok-silent.mp4` и наложить звук из библиотеки TikTok — подписи уже в кадре.
